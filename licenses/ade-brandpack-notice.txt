Changes: lossless SVG rasterisation to a 512 px PNG; campaign image resized
proportionally from 2560x1440 to 1024x576 and encoded as WebP, without cropping,
recolouring or changing its composition. The logo is placed unaltered on a
yellow signs, entrance flags and DJ-table fascia, with a separate independent-concept
disclosure. The black campaign image is retained as a source reference but is no
longer displayed or included in the built site.
Source checksums and a deterministic recipe are in scripts/build-ade-brandpack.mjs.

Default production builds exclude concept-assets/. Only an explicit
npm run build:ade-pitch (or VRCLUB_ADE_PITCH=1) includes the logo for review.
The owner requested a public, non-indexed independent pitch site at
nocturne-ade.mitwee.nl on 18 October 2026. npm run build:ade-site prepares that
site. Non-indexing does not make a public website private, clear third-party
rights or imply an approved ADE collaboration.
